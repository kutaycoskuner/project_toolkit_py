# Timelog

Sample time log for the parser. Each session is one list line: `- <date> <start>-<end>`.
Dates: YYYYMMDD or dd-Mon-yyyy. Times: HH.MM (HH:MM also works).

## September 2025
- 20250927      21.04-22.05
- 20250927      23.30-00.15
- 20250926      01.10-01.35

## Older entries
- 20-Feb-2025   22.20-00.36
- 12-Jun-2025   11.55-12.50
- 09-Jul-2024   21.20-00.00

## Lines the parser skips or reports
- a note without a date is just text and is ignored
- 20250930      9.5-10.00
